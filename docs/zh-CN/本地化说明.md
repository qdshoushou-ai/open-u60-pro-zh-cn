## 3. 构建与部署方法（Windows）

### 3.1 交叉编译

```powershell
# 依赖：rustup 目标 aarch64-unknown-linux-musl、Zig 0.13、cargo-zigbuild
$env:PATH = "C:\Users\Administrator\Downloads\tools\zig-windows-x86_64-0.13.0;" + $env:PATH
cd C:\Users\Administrator\Downloads\open-u60-pro
cargo zigbuild --release --target aarch64-unknown-linux-musl -p zte-agent
```

产物：`target\aarch64-unknown-linux-musl\release\zte-agent`（静态 musl，可直接在设备运行）。

### 3.2 部署（ADB，本机已验证）

一键脚本：`C:\Users\Administrator\Downloads\deploy-u60pro.ps1`（构建 → `adb push` → 安装 A/B 槽位 → 重启 Agent → 校验登录）。

设备上的布局（与官方 `deploy.sh` 一致）：

```
/data/open-u60/update/slot-a/zte-agent      # 活动槽位
/data/open-u60/update/slot-b/zte-agent      # 回退槽位
/data/open-u60/update/{active,pending}      # A/B 状态
/data/open-u60/update/slot-*/bootstrap.sha256
/data/local/tmp/zte-agent-supervisor.sh     # 启动/回退监督脚本
/data/local/tmp/start_zte_agent.sh          # 启动脚本（含 ZTE_AGENT_PASSWORD）
/data/zte-agent -> slot-a/zte-agent         # 兼容软链接
/etc/rc.local                               # 已追加：sh /data/local/tmp/start_zte_agent.sh
```

说明：
- `/tmp/zte-agent.log` 为 Agent 日志；监听 `0.0.0.0:9090`（移动数据侧默认被拒绝，仅 LAN/回环可用）。
- 重启后由 `rc.local` 调起监督脚本，监督脚本校验槽位哈希/可执行性后启动；启动失败自动回退另一个槽位。
- 本次构建**未注入 OTA 签名公钥**，因此控制台“Agent 更新”页会提示“此开发构建没有版本校验密钥”，OTA 下载安装不可用；更新请重新执行部署脚本。

### 3.3 修改控制台密码

```powershell
adb shell "sed -i \"s/^export ZTE_AGENT_PASSWORD=.*/export ZTE_AGENT_PASSWORD='新密码'/\" /data/local/tmp/start_zte_agent.sh"
adb shell "killall zte-agent; sleep 1; sh /data/local/tmp/start_zte_agent.sh"
```

### 3.4 卸载 / 回退

```powershell
adb shell "sed -i '/start_zte_agent.sh/d' /etc/rc.local; killall zte-agent"
adb shell "rm -rf /data/open-u60 /data/local/tmp/start_zte_agent.sh /data/local/tmp/zte-agent-supervisor.sh /data/zte-agent"
```

## 4. 验证结果（2026-11-21）

- 交叉编译成功；设备上 `zte-agent --version` = `0.1.0`，登录 API 200，`/console/` 返回 `lang="zh-CN"`。
- 用 Edge + Playwright 自动化遍历 36 个页面：**36/36 页面显示中文标题与描述，0 个前端运行错误**（截图含真实网络数据，故不随仓库公开）。
- 移动网络实况：CMCC、5G SA、RSRP −98 dBm、电池 82%（充电中）、在线状态正常读取。
- 已知非中文提示来源（设备侧，不是未翻译项）：`/api/esim/profiles` 在未插 eSIM 卡时返回 QMI `SimFileNotFound`（页面显示“不可用”）；内核版本字符串、进程名、主机名为设备原始数据。

## 5. 已知限制

1. iOS App 需在 macOS + Xcode 编译；Android App 需 Android SDK/Gradle 编译。本机只完成源码中文化，未产出安装包。
2. OTA 签名更新不可用（见 3.2）；需要时可在 `release.yml` 同等流程注入 `ZTE_OTA_PUBLIC_KEY_PEM` 后重新构建。
3. 旧 `/ui/` 服务端页面（`zte-agent/src/web/`）未翻译，但已被 303 重定向到 `/console/`，不影响使用。
4. 内部开发文档（`docs/research/`、`CLAUDE.md`、脚本注释、`ui/tests/` 中的测试夹具数据）保持英文。
5. 浏览器端旧测试套件需要 Playwright 与 `/tmp` 路径（POSIX），本机未运行；纯 Node 测试（11 个）已通过。
