# 响应式 Web 控制台

`/console/` 上的控制台是唯一用于生产的浏览器界面。`/` 和已退役的 `/ui/` 书签都会重定向到它；已知的旧页面会映射到对应的 hash 路由，且不转发查询字符串。旧 UI 的表单提交、资产 URL 和实时流返回 410，且无法修改设置。共享的安全/证书辅助代码和归档的渲染器测试夹具仍在内部保留；旧渲染模块只为测试而编译。

## 界面

五个主区域是仪表盘、网络、短信、工具和设置。手机使用固定的底部导航和可横向滚动的二级标签页。平板和桌面使用可展开的侧边栏分组。同一导航元素在手机上会移到文档级停靠位置，位于固定页头、滚动面板和页面动画之外。当键盘缩小或平移可视区域时，可视视口变化会让停靠栏和对话框保持在视野内。触屏横屏的矮布局仍保留停靠栏。内容会为停靠栏和安全区域预留空间。

浅色、深色和跟随系统外观适用于每个屏幕。页面和对话框过渡使用透明度与变换；快速导航会停留在最新路由。减少动效偏好和隐藏的标签页会跳过或立即完成过渡。实时数字在变化的数位播放动画时，保留其最新的无障碍值。地址、标识符和可编辑字段保持字面显示。表单在路由切换和 SSE 更新之间保留草稿。

## 认证与传输

静态资源位于 `/console/a/`。外壳不包含任何设备读数。提供外壳之前会应用其 Host 允许列表和严格 CSP；未设置 Agent 密码时，控制台会把用户引导到独立的 `/console/setup` 页面。设备读取、写入和流式传输沿用现有的已认证 JSON API 及其 Host/Origin 校验、登录限流和阻塞工作通道。控制台不会取代上游的随机令牌认证实现、CLOCK_BOOTTIME 过期、局域网准入检查或 TLS 监听器。

持有者令牌保存在本标签页的 `sessionStorage` 中；密码在登录后即被清除，且从不持久化。导航和重新加载会保留该标签页会话。显式锁定或过期会清除令牌、读数和草稿。较旧登录迟到的未授权响应不会锁定较新的会话。eSIM ICCID 在文本中做了掩码，并使用不透明的 DOM 键；命令所需的完整标识符只保留在已认证的内存状态中。

## 实时数据

`GET /api/dashboard/events` 是需认证的 axum SSE 响应。它先发送快照，随后以 `{readings: {name: {ok, data, error}}}` 信封发送变化的读数，并附带注释心跳。其异步响应不占用 API 通道，也不引入额外的 HTTP 监听器。流上限为八条，在过期/吊销时结束，并在达到最大存活期后重连。丢弃最后一个订阅会丢弃已保存的读数。没有查看者时，采集器休眠，既不轮询也不采样。

基础读数包括设备、WAN/WAN6、信号、调制解调器/移动状态、充电、速率、电池、Wi-Fi/访客网络和已记住的客户端。`sms=1` 只在消息页面启用短信数据。可选的 `topics` 为 `clients`、`routing`、`esim`、`operators`、`forwarding`、`health`、`power`、`https`、`radio`、`speedtest` 和 `terminal`。订阅者只接收自己选中的可选数据；共享快照在最后一个订阅者离开时丢弃。固件通知和成功的 API 变更会加速采样。现有的 `/api/events` API 仍然可用；`/ui/` 流式传输已退役。

WAN IPv4 和 IPv6 使用各自独立的固件接口，并显示所有上报的地址；委派前缀不会被误标为接口地址。缺失的地址会明确标出。设备速率来自经过校验的 Wi-Fi 关联字节计数器，并使用单调递增的经过时间计算。AP RX 即设备上传；AP TX 即设备下载。观测峰值只覆盖持续受监控的关联，并在计数器复位、重新关联、接口变化或监控中断后复位。链路速率、观测速率和配置上限三者相互独立。不支持按设备上限的固件会报告 null/“Not reported”。

eSIM 主题只读取已保存的 Agent 状态；它从不打开卡片通道或发送回执。显式的配置文件读取和普通页面加载使用现有的 eSIM API。配置文件变更带有新鲜状态校验和回读；下载在安装前需要运营商预览。确认、取消和关闭都带有任务标识，因此过期的预览无法作用于另一个任务。不确定的操作从不自动重试。迟到的命令响应无法覆盖更新的 SSE 进度。

## 电池与电源

工具 → 电池与电源订阅可选的 `power` 主题（查看期间每五秒采样一次）。`battery_details` 将 Linux 电源测量的只读允许列表与缓存的固件电池/充电器数据以及当前充电策略合并。查看页面不会改变任何充电控制。标识符和可写的 sysfs 字段被排除在外。

电池和 USB 功率使用实测电压 × 电流并按 µV/µA 换算，不依赖不可靠的驱动 `power_now`。电池电量流向与 USB 输入相互独立。内核时间估算以秒为单位；现有固件估算以分钟为单位。非正数/哨兵值的估算视为不可用，充电估算在充电/充满状态之外被抑制。原始来源字段保留在可折叠的详情区。缺失数据不等于零；中断的流会保留数值并显示过期说明，锁定或离开页面会清除其可选数据。

## 源码与检查

- `zte-agent/ui/`：无依赖的 HTML、CSS 和浏览器模块。
- `src/console.rs`：静态外壳/资产与 Host/CSP 处理。
- `src/dashboard.rs`、`dashboard_extra.rs`、`client_details.rs`：按需读数、有界异步 SSE 和客户端测量。
- `ui/tests/`：纯 Node 校验检查和 Playwright 浏览器测试夹具。它们从不连接路由器，也不修改真实设置。

用 Node 运行纯检查（`actions`、`advanced`、`battery-model`、`cellular`、`clients-model`、`esim-model`、`routing-model`）。浏览器测试套件（`https`、`battery`、`dashboard`、`controls`、`workspaces`、`routing`、`clients`、`esim`、`session`、`numbers`、`navigation`）使用 Playwright 和 Chrome；`navigation` 还会使用 WebKit。`PLAYWRIGHT_WEBKIT_EXECUTABLE` 可以选择 Playwright 默认路径之外的已安装包。Rust 检查使用 `cargo test -p zte-agent --locked` 和常规的 aarch64-musl 发布构建。

## 公开截图

`ui/screenshots/` 包含该控制台的渲染截图，使用虚构的读数、名称和配置文件标识符。WAN 地址使用 RFC 文档地址段；设备 MAC 使用本地演示值。其中不包含真实探测截图、短信正文、凭据、激活码、EID 或个人设备标识符。现有的 iOS 截图库仍位于 `mobile/ios/screenshots/`。

## HTTPS 与已安装的快捷方式

设置 → HTTPS 与安装会订阅 `topics=https`，在查看期间每五秒获取一次状态更新。现有 TLS 服务通过慢速工作通道提供需确认的持有者认证 `POST /api/https/on`、`/renew` 和 `/reset` 命令。Host/Origin 准入和登录限制保持不变。启用 HTTPS 时，证书/描述文件下载仍公开可用；私钥永不提供。新屏幕包含到期时间、路由器时钟可信状态、证书颁发机构指纹以及各平台的信任/安装说明。

`/console/manifest.webmanifest` 和旧的 `/ui/manifest.webmanifest` 都保留已安装应用 id `/ui/`，起始地址为 `/console/`，作用域覆盖根路径。公开的图标别名只提供生成的图标，从不提供旧脚本或样式。生产路由器不再挂载服务端渲染界面。其归档测试使用显式的仅测试用测试夹具；生产退役状态和 HTTPS API 安全性通过 `httpd::app` 进行测试。
